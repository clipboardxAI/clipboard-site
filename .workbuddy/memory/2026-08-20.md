# 2026-08-20

## Fixed mobile nav double-locale-prefix bug

- **Problem**: Mobile menu panel in SiteNav.vue showed `/zh-CN/zh-CN/marketplace/` etc. (double locale prefix) on all non-English locale pages.
- **Root cause**: `config.ts` `tc()` function already prepends locale prefix to all nav links (e.g., `/zh-CN/marketplace/`). But `SiteNav.vue`'s `navItems` computed passed these already-prefixed links through `localeLink()` again, causing double-prefixing. Desktop nav (`VPNavBarMenu`) was unaffected because it reads `theme.value.nav` directly.
- **Fix**: Removed `localeLink()` wrapping in `navItems` computed — links from `theme.value.nav` are used as-is. Removed unused `localeLink` import.
- **Verified**: Build passes, all generated HTML checked — zero double-prefix instances across all 7 locales.
