# 使用指南

## 剪贴板历史

ClipboxAI 运行在**菜单栏**中。每当你复制内容时，它都会添加到历史记录。

- 点击菜单栏图标，打开历史面板。
- 将鼠标悬停在某个条目上并按下操作快捷键，或点击将其复制回粘贴板。
- 使用搜索框，按文本查找条目。

## AI 工具窗口

**AI 工具（AI Tool）** 窗口是操作运行的地方。它采用分栏布局：

- **左侧**——工具列表，分为：
  - **内置 AI（Built-in AI）**——总结、翻译及其他 AI 操作。
  - **内置本地（Built-in Local）**——离线工具（提取链接、字数统计、压缩空行）。
  - **已安装（Installed）**——你从 Marketplace 添加的操作。你可以拖动以**重新排序**。
- **右侧**——两个面板：一侧是**原始**剪贴内容，另一侧是**结果**。

AI 工具显示「云」标识；本地工具显示「设备」标识，因此你始终清楚某项操作是否使用网络。

## 运行操作

1. 从左侧列表中选择一个工具（或接受智能建议）。
2. 当前剪贴内容会显示在**原始**面板中。
3. 结果会在**结果**面板中生成。

### 自动运行（Auto-run）

在窗口底部打开 **输出时自动运行（Auto-run on output）**。启用后，只要一复制内容，所选工具就会自动运行——无需手动点击。本地工具永远不会覆盖你的粘贴板，因此自动运行是安全的。

## 内置本地工具

这些工具完全在 Mac 上离线运行：

- **提取链接（Extract Links）**——返回文本中发现的每一个 URL。
- **字数统计（Count Stats）**——单词 / 字符 / 行数 / 句子数统计。
- **压缩空行（Collapse Blank Lines）**——移除粘贴文本中的空行。

## 云端 AI 设置

要使用 AI 操作，请在 **设置 → AI（Settings → AI）** 中连接一个提供商：

1. 选择提供商——**DeepSeek**、**MiniMax**、**Zhipu GLM**、**Kimi (Moonshot)**、**Mistral**、**Ollama**（本地），或其他 OpenAI 兼容服务。
2. 粘贴你的 **API key**。它保存在 **Keychain** 中，绝不会以明文写入磁盘。
3. 选择一个模型。
4. 云端 AI 默认关闭。启用后，你的剪贴内容只会发送给所配置的提供商。

如果未设置 key，配置横幅会在 AI 工具窗口中提醒你。

## 操作市场（Marketplace）

1. 从 AI 工具窗口打开 **Marketplace**（或站点的 [Marketplace](/zh-CN/marketplace/) 页面）。
2. 在某个操作上点击 **安装（Install）**。这会通过深链接 `clipboxai://install?action=<id>` 打开应用，并将该操作添加到你的 **已安装（Installed）** 列表。

## 键盘快捷键

| 快捷键 | 操作 |
|----------|--------|
| `Cmd+Shift+V` | 打开剪贴板历史 |
| `Cmd+,` | 打开设置 |
| `Cmd+W` | 关闭窗口 |
| `Cmd+Q` | 退出应用 |

> 具体快捷键可能因版本而异；请在应用内的 **设置 → 快捷键（Settings → Shortcuts）** 中查看。

## 设置

打开 **ClipboxAI → 设置（Settings）**（或按 `Cmd+,`）：

- **通用（General）**：语言、登录时启动、外观主题。
- **AI**：云端提供商、模型与 API key（Keychain）。
- **操作（Actions）**：自动运行开关、排除的应用、工具顺序。
- **隐私（Privacy）**：云端 AI 选择性开启、排除的应用、历史记录控制。
- **Marketplace**：浏览并管理已安装的操作。
