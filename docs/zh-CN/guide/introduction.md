# 简介

## 关于 ClipboxAI

**ClipboxAI** 是一款面向 macOS 的智能剪贴板管理器。每当你复制文本、代码或链接时，它都会保存到菜单栏中一处可搜索的历史记录里。只需点击一下——或者完全自动地——你就能对该剪贴内容执行一项操作：总结、翻译、整理，或交给云端 AI 模型处理。

它围绕两类工具构建：

- **内置本地工具**：完全在你的 Mac 上运行，无需联网。
- **AI 操作**：调用你自行配置的云端模型（使用你自己的 API key，保存在系统 Keychain 中）。

## 核心功能

### 📋 剪贴板历史

你复制的一切都会被自动捕获，并保存在可搜索的历史记录中。从菜单栏随时回到任意一条历史剪贴内容——再也不用担心片段丢失。

### ⚡ 智能建议

ClipboxAI 会根据当前剪贴内容，推荐最相关的操作。你可以接受建议，也可以浏览完整的工具列表。

### 🛠️ 内置本地工具

离线、私密、即时：

- **提取链接（Extract Links）**——从一段文本中抽出所有 URL。
- **字数统计（Count Stats）**——统计单词、字符、行数和句子数。
- **压缩空行（Collapse Blank Lines）**——一步整理粘贴的文本。

未来还会持续增加更多本地工具——它们永远不会离开你的设备。

### ✨ AI 操作

将当前剪贴内容发送到云端模型，以：

- **总结（Summarize）**长文章与长篇讨论。
- **翻译（Translate）**不同语言之间的内容。
- **改写 / 润色（Rewrite / polish）**语气与表达。
- 运行 **Marketplace** 中的任意操作。

### 🛒 操作市场（Action Marketplace）

浏览社区创建的 AI 操作，并通过深链接（`clipboxai://install?action=<id>`）一键安装。分类包括：写作、开发、效率、翻译、社交与分析。

### 🔒 以隐私为本

你的剪贴板历史始终留在你的设备上。云端 AI 是**可选开启**的：开启后，内容只会发送到你*自己*选择的提供商，使用的是保存在你 Keychain 中的 API key。我们从不接收或存储你的剪贴内容，也没有任何分析或遥测。

## 系统要求

- **操作系统**：macOS 14 Sonoma 或更高版本
- **CPU**：Apple Silicon（M 系列）或 Intel（64 位）
- **内存**：最低 4 GB，推荐 8 GB
- **存储空间**：安装约需 50 MB
- **云端 AI 所需**：来自受支持提供商（DeepSeek、MiniMax、Zhipu GLM、Kimi、Mistral、Ollama、OpenAI、Anthropic 或 Gemini）的 API key

## 支持的语言

本应用与本站支持 7 种语言：English、简体中文、繁體中文、日本語、德语、西班牙语、法语。
