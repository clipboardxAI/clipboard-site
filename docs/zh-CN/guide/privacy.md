# 隐私政策

ClipboxAI 是一款面向 macOS 的智能剪贴板管理器。你的隐私是我们的首要考量。

## 本地优先设计（Local-First Design）

- 你的剪贴板历史完全保存在你的 Mac 上。
- 内置本地操作（提取链接、字数统计、压缩空行，以及设备端 ML 建议）完全离线运行。
- 使用核心应用无需账号或注册。
- 本地剪贴板管理与设备端功能无需网络连接。

## 云端 AI（可选，Cloud AI）

ClipboxAI 可选择使用云端 AI 提供商（如 DeepSeek、MiniMax、GLM、Kimi、Mistral，或本地 Ollama 服务器）来支撑总结、翻译、自定义提示等高级操作。

- 启用后，所选文本或剪贴内容会使用**你自己的 API key**，**直接发送到你配置的提供商**。
- 你的 API key 仅保存在你 Mac 的 Keychain 中，绝不会上传给我们。
- 你可以随时关闭云端 AI，继续使用本地功能。
- 剪贴板历史**不会**自动发送到云端；云端请求仅在你运行某项云端操作时才会触发。

## 我们不作收集的内容

- 我们不收集你的剪贴板内容、文档或文件。
- 我们不追踪你的活动、浏览行为或使用模式。
- 我们不运营任何接收你剪贴板数据的服务器。
- 我们不包含任何第三方分析、广告或追踪 SDK。
- 我们没有任何遥测系统。

## 本地存储哪些数据

以下数据仅保存在你的设备上：

- **剪贴板历史**：便于快速访问的最近条目（保存在你的 Mac 上）。
- **应用设置**：主题、语言偏好、已启用操作、提供商配置。
- **API key**：安全地保存在本地 Keychain 中（仅在你配置了云端提供商时）。
- **自定义操作**：你创建的提示词与配置。
- **日志**：用于故障排除的调试日志（可随时删除）。

## 应用使用的权限

- **辅助功能 / 完全磁盘访问（Accessibility / Full Disk Access）**：读取系统剪贴板并提供全局快捷键所需。
- **通知（Notifications）**：可选，用于长时间云请求的完成提醒。

你可以随时在 **系统设置 → 隐私与安全性（System Settings → Privacy & Security）** 中管理这些权限。

## 应用内购买 / 许可

许可购买（如有）由 Apple 通过 Mac App Store 处理。ClipboxAI 不接收或存储你的支付信息。许可凭证保存在本地以验证所有权。

## 第三方服务

ClipboxAI 本身不包含任何第三方分析、广告或追踪服务。当你启用某个云端 AI 提供商时，你的请求由该提供商按其自身的隐私政策处理。

## 隐私请求

由于 ClipboxAI 将所有数据本地保存在你的设备上，我们的服务器上不持有任何个人数据。如果你对隐私有疑问，请联系我们。

## 联系方式

如有隐私相关问题，请在 [GitHub Issues](https://github.com/clipboxAI/clipboard-site/issues) 上提交 issue，或发送邮件至 clipboxai@w3cub.com。
