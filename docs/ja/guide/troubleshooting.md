# トラブルシューティング

このページは、macOS 上の ClipboxAI でよくある問題とその解決方法をまとめたものです。

## アプリが起動しない、または起動時にクラッシュする

1. macOS のバージョンが最小要件（macOS 14 Sonoma 以上）を満たしているか確認してください。
2. アプリを終了して再起動してください。
3. Mac を再起動してください。
4. ~~GitHub Releases からダウンロードした場合は、最新または公証済みのビルドをお試しください。~~
5. 問題が続く場合は、ログ（下記）を収集して issue を作成してください。

## クリップボード履歴にコピーが記録されない

症状: 新しいコピーが履歴パネルに表示されない。

チェックリスト：

1. アプリが動作しており、メニューバーのアイコンが表示されていることを確認してください。
2. **Clipboard monitoring（クリップボード監視）** が **設定 → プライバシー / 一般** で有効になっていることを確認してください。
3. アプリはバックグラウンドでペーストボードを読み取るために該当の macOS 権限が必要です — [権限](/ja/guide/permissions)を参照してください。
4. 一部のアプリ（パスワードマネージャーやセキュア入力フィールド）は意図的にクリップボードへのアクセスをブロックします。これは仕様です。

## クラウド AI アクションが結果を返さない

症状: AI アクションが失敗、フリーズ、または設定エラーを表示する。

チェックリスト：

1. **設定 → AI** を開き、プロバイダーが選択され、キーが入力されていることを確認してください。
2. そのキーがプロバイダーに対して有効で、クォータ/クレジットがあることを確認してください。
3. ネットワーク接続を確認してください — クラウド AI にはインターネット接続が必要です。
4. 選択したモデル名がプロバイダーに対して正しいことを確認してください。
5. AI ツールウィンドウに設定バナーがまだ表示される場合、キーが Keychain に保存されていません。再度入力してください。

## マーケットプレイスのインストールでアクションが追加されない

症状: **Install** をクリックしても何も起きない、あるいはアプリが開かない。

チェックリスト：

1. ディープリンク `clipboxai://install?action=<id>` はインストール済みのアプリで処理される必要があります — ClipboxAI がインストールされ、動作していることを確認してください。
2. ブラウザーがディープリンクをブロックする場合は、リンクをコピーして手動で開くか、アプリ内の **Marketplace** タブからインストールしてください。
3. そのアクション ID がマーケットプレイスにまだ公開されているか確認してください。

## アプリのリセット

設定をリセットし、ローカルデータを消去するには：

1. ClipboxAI を終了します。
2. コンテナを削除します（これにより履歴と設定が削除されます）：

```bash
rm -rf ~/Library/Containers/com.w3cub.clipboard
```

3. アプリを再度開き、再設定を行います。Keychain 内の API key は必要に応じて **Keychain Access** で別途削除してください。

## デバッグログの収集方法

```bash
# 共有用にログをデスクトップにコピー
cp ~/Library/Containers/com.w3cub.clipboard/Data/Library/Logs/ClipboxAI/*.log ~/Desktop/ 2>/dev/null
```

その後、[GitHub](https://github.com/clipboxAI) で issue を作成し、ログを添付してください。

## 問題を報告する

issue を作成する際は、以下を含めてください。

- macOS のバージョン（Apple メニュー → この Mac について）
- ClipboxAI のバージョン（アプリメニュー → バージョン情報）
- 再現手順
- ログ（上記参照）

これにより、メンテナーが問題を特定して解決しやすくなります。
