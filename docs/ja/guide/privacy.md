# プライバシーポリシー

ClipboxAI は macOS 向けのスマートなクリップボードマネージャーです。お客様のプライバシーを最優先に考えています。

## ローカルファーストの設計

- クリップボードの履歴は、お客様の Mac 上のみに保存されます。
- 内蔵のローカルアクション（リンク抽出、集計、空白行削除、および端末上の ML による提案）は完全にオフラインで動作します。
- コアアプリを利用するためにアカウントや登録は不要です。
- ローカルのクリップボード管理や端末上の機能にはインターネット接続は不要です。

## クラウド AI（任意）

ClipboxAI は、任意でクラウド AI プロバイダー（DeepSeek、MiniMax、GLM、Kimi、Mistral、またはローカルの Ollama サーバーなど）を使用し、要約・翻訳・カスタムプロンプトなどの高度なアクションを実現できます。

- 有効にした場合、選択したテキストやクリップボードの内容は、**ご自身で設定したプロバイダーに直接**、**ご自身の API key** を使って送信されます。
- API key はお客様の Mac の Keychain にのみ保存され、私たちへアップロードされることはありません。
- クラウド AI はいつでも無効にでき、その後もローカル機能を引き続き利用できます。
- クリップボード履歴が自動的にクラウドへ送信されることは**ありません**。クラウドへのリクエストは、クラウドアクションを実行したときにのみ発生します。

## 私たちが収集しないもの

- クリップボードの内容、ドキュメント、ファイルを収集しません。
- お客様のアクティビティ、閲覧行動、利用パターンを追跡しません。
- お客様のクリップボードデータを受信するサーバーを運用していません。
- サードパーティのアナリティクス・広告・追跡用 SDK を含みません。
- テレメトリシステムは一切存在しません。

## ローカルに保存されるデータ

以下のデータはお客様のデバイスのみに保存されます。

- **クリップボード履歴**: すばやくアクセスするための最近の項目（Mac 上に保持）。
- **アプリ設定**: テーマ、言語の設定、有効なアクション、プロバイダーの設定。
- **API key**: ローカルの Keychain に安全に保存（クラウドプロバイダーを設定した場合のみ）。
- **カスタムアクション**: お客様が作成したプロンプトと設定。
- **ログ**: トラブルシューティング用のデバッグログ（いつでも削除可能）。

## アプリが使用する権限

- **アクセシビリティ / フルディスクアクセス**: システムのクリップボードの読み取りとグローバルショートカットの提供に必要。
- **通知**: 時間のかかるクラウドリクエストの完了通知用（任意）。

これらの権限はいつでも **システム設定 → プライバシーとセキュリティ** で管理できます。

## アプリ内課金 / ライセンス

ライセンスの購入（ある場合）は、Apple を通じて Mac App Store 経由で処理されます。ClipboxAI がお客様の決済情報を受け取ったり保存したりすることはありません。ライセンスのレシートは、所有権の確認のためローカルに保存されます。

## サードパーティサービス

ClipboxAI 自体にはサードパーティのアナリティクス・広告・追跡サービスは含まれていません。クラウド AI プロバイダーを有効にした場合、お客様のリクエストはそのプロバイダー自身のプライバシーポリシーに基づいて処理されます。

## プライバシーに関するご要望

ClipboxAI はすべてのデータをお客様のデバイスにローカルに保存するため、私たちのサーバー上に個人データを保持していません。プライバシーについてご質問がある場合は、お問い合わせください。
