# はじめに

## ClipboardxAI について

**ClipboardxAI** は macOS 向けのスマートなクリップボードマネージャーです。テキスト・コード・リンクをコピーするたびに、それらが検索可能な履歴としてメニューバーに保存されます。ワンクリック、あるいは完全に自動で、そのクリップに対してアクションを実行できます。要約したり、翻訳したり、整えたり、クラウドの AI モデルに渡したりすることが可能です。

このアプリは、次の 2 種類のツールを中心に構成されています。

- **内蔵のローカルツール** — Mac 上のみで動作し、ネットワーク接続を一切行いません。
- **AI アクション** — ご自身で設定したクラウドモデル（システムの Keychain に保存されたご自身の API key）を呼び出します。

## 主な機能

### 📋 クリップボード履歴

コピーしたものはすべて自動的にキャプチャされ、検索可能な履歴に保存されます。メニューバーから過去のクリップにいつでも戻ることができ、失われたスニペットともお別れです。

### ⚡ スマートな提案

ClipboardxAI は、現在のクリップに最も関連性の高いアクションを提案します。提案を受け入れることも、ツールの一覧から探すこともできます。

### 🛠️ 内蔵のローカルツール

オフライン・プライベート・即時実行：

- **Extract Links（リンク抽出）** — テキストブロックからすべての URL を取り出します。
- **Count Stats（集計）** — 単語数・文字数・行数・文の数をカウントします。
- **Collapse Blank Lines（空白行の削除）** — 貼り付けたテキストを一手順で整えます。

今後もローカルツールは追加されていく予定ですが、いずれも端末の外には出ません。

### ✨ AI アクション

現在のクリップをクラウドモデルに送信して、次のことができます。

- **Summarize（要約）** — 長文の記事やスレッドを要約します。
- **Translate（翻訳）** — 言語間で翻訳します。
- **Rewrite / polish（書き直し・推敲）** — トーンと明快さを整えます。
- **Marketplace** の任意のアクションを実行します。

### 🛒 アクションマーケットプレイス

コミュニティ製の AI アクションを閲覧し、ディープリンク（`clipboardxai://install?action=<id>`）からワンクリックでインストールできます。カテゴリーには Writing、Developer、Productivity、Translate、Social、Analytics があります。

### 🔒 設計段階からプライベート

クリップボードの履歴はお使いのデバイスに留まります。クラウド AI は**オプトイン（任意）**です。有効化した場合でも、コンテンツが送信されるのは *あなた* が選んだプロバイダーだけであり、Keychain に保存された API key が使用されます。私たちがクリップを受信したり保存したりすることは一切なく、アナリティクスやテレメトリも存在しません。

## システム要件

- **オペレーティングシステム**: macOS 14 Sonoma 以降
- **CPU**: Apple Silicon（M シリーズ）または Intel（64 ビット）
- **メモリ**: 最小 4 GB RAM、推奨 8 GB
- **ストレージ**: インストールに約 50 MB
- **クラウド AI の場合**: 対応プロバイダーの API key（DeepSeek、MiniMax、Zhipu GLM、Kimi、Mistral、Ollama、OpenAI、Anthropic、または Gemini）

## 対応言語

このアプリと本サイトは、英語、简体中文（簡体字中国語）、繁體中文（繁体字中国語）、日本語、ドイツ語（German）、スペイン語（Spanish）、フランス語（French）の 7 言語に対応しています。
