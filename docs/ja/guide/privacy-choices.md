# プライバシーの選択肢

ClipboardxAI はローカルファーストのアプリケーションです。データはお客様のデバイスに留まるため、私たちが個人情報を収集・販売・共有することはありません。

## ローカルに保持するデータ

ClipboardxAI はすべてのデータをお客様の Mac にローカルに保存します。

- クリップボード履歴とアプリの設定
- カスタムアクションと設定
- API key（Keychain 内、クラウドプロバイダーを設定した場合のみ）
- デバッグログ（有効な場合）

これらのデータがアプリ自身によってサーバーへアップロードされることはありません。

## クラウド AI のオプトイン

クラウド AI 機能は**既定でオフ**です。コンテンツが送信されるのは、お客様が選んだプロバイダーに、ご自身の API key を使って、かつクラウドアクションを実行したときだけです。設定済みのプロバイダーは **設定 → AI** で確認または削除できます。

## お客様の権利

ClipboardxAI はサーバー上に個人データを収集・保存しないため、私たちがアクセス・削除・移転すべき個人データは存在しません。すべてのデータは、アプリ内で直接管理するか、アプリのコンテナフォルダーを削除することで管理できます。

```bash
rm -rf ~/Library/Containers/com.w3cub.clipboard
```

## 販売しない

ClipboardxAI はいかなる個人情報も販売しません。種類を問わず、サードパーティのアナリティクス・広告・追跡サービスは使用していません。
