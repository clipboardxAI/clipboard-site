# Privacy Choices

Clipboard x AI is a local-first application. Because your data stays on your device, we do not collect, sell, or share any personal information.

## Data We Hold Locally

Clipboard x AI stores all data locally on your Mac:

- Clipboard history and app preferences
- Custom actions and configuration
- API keys (in the Keychain, only if you configure a cloud provider)
- Debug logs (if enabled)

None of this data is uploaded to any server by the app itself.

## Cloud AI Opt-In

Cloud AI features are **off by default**. They send content only to the provider you choose, using your own API key, and only when you trigger a cloud action. You can review or delete configured providers in **Settings → AI**.

## Your Rights

Since Clipboard x AI does not collect or store personal data on our servers, there is no personal data for us to access, delete, or transfer. All your data can be managed directly within the app or by removing the app's container folder:

```bash
rm -rf ~/Library/Containers/com.w3cub.clipboard
```

## Do Not Sell

Clipboard x AI does not sell any personal information. We do not use third-party analytics, advertising, or tracking services of any kind.
