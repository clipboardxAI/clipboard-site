# 簡介

## 關於 ClipboardxAI

**ClipboardxAI** 是一款專為 macOS 打造的智慧剪貼簿管理工具。每當你複製文字、程式碼或連結時，都會被儲存到選單列中可搜尋的歷史紀錄裡。只要點一下——或是完全自動地——你就能對該筆剪貼內容執行動作：摘要、翻譯、整理，或是交由雲端 AI 模型處理。

它的設計圍繞兩類工具：

- **內建本地工具**：完全在你的 Mac 上執行，不需要任何網路連線。
- **AI 動作**：呼叫你自行設定的雲端模型（使用你自己的 API key，儲存在系統 Keychain 中）。

## 主要功能

### 📋 剪貼簿歷史

你複製的一切都會自動被擷取並保存在可搜尋的歷史紀錄中。從選單列隨時回到任何先前的剪貼內容——不再遺失任何片段。

### ⚡ 智慧建議

ClipboardxAI 會針對目前的剪貼內容建議最相關的動作。你可以接受建議，也可以瀏覽完整的工具清單。

### 🛠️ 內建本地工具

離線、私密、即時：

- **擷取連結（Extract Links）** — 從一段文字中擷取出所有 URL。
- **統計計數（Count Stats）** — 字數、字元數、行數與句數統計。
- **摺疊空白行（Collapse Blank Lines）** — 一步整理貼上的文字。

未來會陸續加入更多本地工具——它們永遠不會離開你的裝置。

### ✨ AI 動作

將目前的剪貼內容送到雲端模型以：

- **摘要** 長篇文章與串文。
- **翻譯** 不同語言之間的內容。
- **重寫 / 潤飾** 語氣與清晰度。
- 執行來自 **Marketplace** 的任何動作。

### 🛒 動作市集（Action Marketplace）

瀏覽社群製作的 AI 動作，並透過深層連結（`clipboardxai://install?action=<id>`）一鍵安裝。分類包含寫作、開發者、生產力、翻譯、社群與分析。

### 🔒 以隱私為本

你的剪貼簿歷史始終保留在你的裝置上。雲端 AI 是**可選功能**：啟用後，內容只會傳送給*你*選擇的供應商，並使用儲存在你 Keychain 中的 API key。我們絕不接收或儲存你的剪貼內容，也不會收集任何分析數據或遙測資訊。

## 系統需求

- **作業系統**：macOS 14 Sonoma 或以上版本
- **CPU**：Apple Silicon（M 系列）或 Intel（64 位元）
- **記憶體**：最低 4 GB RAM，建議 8 GB
- **儲存空間**：安裝約需 ~50 MB
- **使用雲端 AI**：需要來自建方支援供應商的 API key（DeepSeek、MiniMax、Zhipu GLM、Kimi、Mistral、Ollama、OpenAI、Anthropic 或 Gemini）

## 支援語言

本應用程式與本網站支援 English、简体中文、繁體中文、日本語、德文（German）、西班牙文（Spanish）與法文（French），共 7 種語言。
