# 隱私權政策

ClipboxAI 是一款專為 macOS 打造的智慧剪貼簿管理工具。你的隱私是我們的首要考量。

## 本機優先設計

- 你的剪貼簿歷史完全儲存在你的 Mac 上。
- 內建本地動作（擷取連結、統計計數、摺疊空白行，以及裝置端 ML 建議）完全離線執行。
- 使用核心應用程式不需要任何帳號或註冊。
- 本地剪貼簿管理與裝置端功能不需要任何網際網路連線。

## 雲端 AI（選用）

ClipboxAI 可以選擇性地使用雲端 AI 供應商（例如 DeepSeek、MiniMax、GLM、Kimi、Mistral，或本地的 Ollama 伺服器），來驅動摘要、翻譯與自訂提示等進階動作。

- 啟用後，所選文字或剪貼內容會使用**你自己的 API key**，**直接傳送給你所設定的供應商**。
- 你的 API key 僅儲存在你 Mac 的 Keychain 中，絕不會上傳給我們。
- 你可以隨時停用雲端 AI，繼續使用本地功能。
- 剪貼簿歷史**不會**自動傳送到雲端；雲端請求只有在你執行雲端動作時才會觸發。

## 我們不會蒐集的項目

- 我們不會蒐集你的剪貼簿內容、文件或檔案。
- 我們不會追蹤你的活動、瀏覽行為或使用模式。
- 我們不會營運任何接收你剪貼簿資料的伺服器。
- 我們不包含任何第三方的分析、廣告或追蹤 SDK。
- 我們沒有任何遙測系統。

## 儲存在本地的資料

以下資料僅儲存在你的裝置上：

- **剪貼簿歷史**：供快速存取的最近項目（保留在你的 Mac 上）。
- **應用程式設定**：主題、語言偏好、已啟用的動作、供應商設定。
- **API key**：安全地儲存在本地 Keychain 中（僅在你設定雲端供應商時）。
- **自訂動作**：你建立的提示與設定。
- **日誌**：供疑難排解的除錯日誌（可隨時刪除）。

## 應用程式使用的權限

- **輔助使用／完全磁碟存取**：讀取系統剪貼簿並提供全域快捷鍵所需。
- **通知**：選用，用於長時間雲端請求完成時的提醒。

你可以隨時在 **System Settings → Privacy & Security（系統設定 → 隱私權與安全性）** 中管理這些權限。

## 應用程式內購買／授權

授權購買（若有）由 Apple 透過 Mac App Store 處理。ClipboxAI 不會接收或儲存你的付款資訊。授權收據會儲存在本地以驗證所有權。

## 第三方服務

ClipboxAI 本身不包含任何第三方的分析、廣告或追蹤服務。當你啟用某個雲端 AI 供應商時，你的請求會由該供應商依其自身的隱私權政策處理。

## 隱私權請求

由於 ClipboxAI 將所有資料儲存在你裝置的本地上，我們的伺服器上並未持有任何個人資料。若你對隱私有任何疑問，請與我們聯繫。

## 聯絡方式

若有隱私權相關問題，請在 [GitHub Issues](https://github.com/clipboxAI/clipboard-site/issues) 開啟一個 issue，或透過電子郵件 clipboxai@w3cub.com 與我們聯繫。
