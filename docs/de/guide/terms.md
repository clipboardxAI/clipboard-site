# Nutzungsbedingungen

Diese Bedingungen regeln Ihre Nutzung von ClipboxAI. Durch das Herunterladen, Installieren oder Nutzen von ClipboxAI stimmen Sie diesen Bedingungen zu. Falls Sie nicht zustimmen, nutzen Sie die Anwendung nicht.

## Lizenz und Nutzung

ClipboxAI wird gemäß den Lizenzbedingungen bereitgestellt, die jeder Veröffentlichung beiliegen. Ihnen wird eine beschränkte, nicht-ausschließliche, nicht-übertragbare Lizenz zur Nutzung der Anwendung auf Ihrem Mac gemäß den Lizenzbedingungen eingeräumt.

## Local-First-Betrieb

ClipboxAI läuft lokal auf Ihrem Gerät für die Zwischenablagen-Verwaltung und On-Device-Funktionen. Es wird kein Zwischenablagen-Verlauf an unsere Server übertragen.

## Cloud-KI-Anbieter

ClipboxAI kann sich mit von Ihnen konfigurierten KI-Anbietern von Drittanbietern verbinden. Ihre Nutzung dieser Anbieter unterliegt deren jeweiligen Bedingungen und Datenschutzrichtlinien. ClipboxAI ist nicht verantwortlich für Inhalt, Verfügbarkeit oder Praktiken von Drittanbieter-Anbietern.

## Käufe

Eine Vollfunktions-Lizenz (falls angeboten) ist über den Mac App Store erhältlich. Alle Käufe werden von Apple abgewickelt. ClipboxAI verarbeitet keine Zahlungsdaten. Die Wiederherstellung von Käufen wird bei Neuinstallationen unterstützt.
