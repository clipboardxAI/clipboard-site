よくある質問

macOS ユーザー向けのクイック回答

ClipboardxAI は無料ですか？
ClipboardxAI は Mac App Store で提供される有料アプリです。購入後は内蔵のローカルツールがすべて含まれ、アカウントは不要です。クラウド AI アクションはご自身の API キーを使用し、料金は AI サービス提供者に直接支払われます。
対応している macOS のバージョンは？
ClipboardxAI は macOS 14 Sonoma 以降が必要です。Apple Silicon（M シリーズ）に最適化されており、Intel もサポートしています。
オフラインで使えますか？
はい。クリップボード履歴と内蔵ローカルツール — リンクの抽出、文字数カウント、空行の折りたたみなど — は Mac 上で完全に動作し、ネットワーク接続は不要です。
クリップボードデータは安全ですか？
クリップボード履歴はあなたのデバイスに保存されます。クラウド AI はオプションであり、設定したサービスのみに内容を送信し、キーチェーンに保存されたキーを使用します。当社がお客様のクリップ内容を受信・保存することはありません。
対応している AI サービスは？
OpenAI 互換のサービスならどれでも — DeepSeek、MiniMax、智譜 GLM、Kimi（月之暗面）、Mistral、ローカルの Ollama — および OpenAI、Anthropic、Gemini に対応しています。

クリップボードをもっと賢くしますか？

ClipboardxAI をダウンロードして、すべてのコピーをアクションに変えましょう — Mac 上でローカルに動作し、AI は必要に応じて有効化できます。
